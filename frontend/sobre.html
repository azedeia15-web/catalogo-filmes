SOBRE O SITE

Um projeto de reviews com identidade própria

Este site foi desenvolvido para organizar conteúdos de filmes, séries e jogos em páginas separadas, com notas, descrições e links relacionados a cada título.

A proposta é manter todas as páginas harmônicas, usando o mesmo estilo vermelho e preto, cards, menus e rodapés para criar uma experiência visual consistente.

Projeto acadêmico

O site foi criado como trabalho acadêmico e utiliza tecnologias simples de front-end, mantendo o foco em organização, navegação entre páginas e apresentação visual.

Tecnologias utilizadas:

HTML Tailwind CSS JavaScript

COMO O SITE FOI PENSADO

🧭

Navegação simples

O menu conecta as páginas principais para que o visitante encontre filmes, jogos e séries com poucos cliques.

🎨

Identidade visual

Preto, vermelho, efeitos de sangue e elementos escuros reforçam a estética de terror e entretenimento do projeto.

🗂️

Conteúdo organizado

Cada categoria possui sua própria página e seus próprios cards, deixando o conteúdo mais fácil de visualizar.

🔗

Links funcionais

Os botões podem levar diretamente para vídeos, histórias, gameplays e outros conteúdos relacionados.

UNIVERSOS DO SITE

O projeto reúne três tipos de entretenimento que aparecem com força no site: cinema, jogos e séries.

CINEMA

Terror e suspense

Filmes sombrios ajudam a definir a estética visual e o clima do site.

GAMES

Jogos e histórias

A página de jogos reúne títulos marcantes, notas e links para conteúdos relacionados.

SÉRIES

Séries e recomendações

Séries recomendadas, notas e links para assistir nas plataformas.
